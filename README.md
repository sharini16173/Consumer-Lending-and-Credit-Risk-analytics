# Consumer Lending Portfolio & Credit Risk Analytics

## About
An analysis of 38,576 loan records to understand how much was lent, how much came back, and how risky the loans were.

## Tools Used
- MySQL: data extraction, aggregation, and quality checks
- Power BI: 3-page interactive dashboard

## What I Did
- Used SQL queries to calculate the key lending numbers
- Built a dashboard with three pages: Summary, Overview, and Details
- Added filters for loan term and home ownership
- Checked every number in the dashboard against my SQL results and they matched

## Key Numbers
- Total funded amount: $435.76M
- Total payments received: $473.07M
- Good loans: 86.18% | Bad loans: 13.82%
- Average DTI ratio: 13.33%
